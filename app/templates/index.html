AI가 내용을 보고 어울리는 장면에 배치합니다. 남는 장면은 기사 이미지나 AI 생성으로 채웁니다.

선택한 영상의 음성을 분석하고, Gemini 키가 있거나 GPT를 선택하면 여러 장면의 화면 내용도 읽습니다. 분석 결과로 연관 영상 후보를 검색하며 업로드 파일도 편집 소재로 쓸 수 있습니다.

참고할 채널의 영상을 넣으면 그 구성·말투를 분석해 지침으로 저장하고, 그 스타일대로 대본을 씁니다.

GPT 연결 · OpenAI API 키 등록

GPT를 선택하려면 별도로 발급받은 OpenAI API 키가 필요하며, 사용량에 따라 요금이 발생할 수 있습니다. OpenAI 키 발급 페이지. 화면에서 등록한 키는 OneDrive 프로젝트 폴더 밖의 Windows 사용자 설정에 저장합니다.

영상 화면 분석 · Gemini API 키 등록

Claude를 선택했을 때 업로드 영상의 화면도 분석하려면 등록하세요. GPT를 선택하면 등록된 OpenAI 키로 화면을 분석합니다. Gemini API는 별도 사용량 요금이 발생할 수 있습니다. Gemini 키 발급 페이지

댓글 자동 수집 · YouTube Data API 키 등록

공개된 유튜브 댓글을 가져와 검토 화면에 보여줍니다. 키가 없어도 영상 제작은 가능합니다. 댓글은 원문 텍스트를 카드로 재구성하며 작성자 이름은 표시하지 않습니다. YouTube Data API 사용 설정

분석 근거 보기

    여기에 유튜브 영상 주소를 최대 5개 붙여넣으세요. 선택한 AI가 자막을 분석해 공통 전개·후킹·감정 흐름·문장 방식을 지침으로 만듭니다. 바로 「만들기」를 눌러도 먼저 자동 분석합니다. 생성된 지침은 수정할 수 있습니다.

    자막이 있는 영상만 분석할 수 있습니다. 화면이나 음악은 분석하지 않습니다. 이번 영상에만 적용됩니다.

    옵션

    클립 재편집은 타인의 영상을 그대로 사용하므로 저작권에 유의하세요. 본인 영상이나 허용된 범위에서만 사용하세요.

    ⚠ 연예·정치 프리셋은 영상 짜깁기 모드입니다. 소스 영상을 내려받아 구간을 잘라 쓰므로 저작권 위험이 있습니다. 소스당 사용 길이를 제한하고 출처를 자동 기재하지만 면책은 아니니, 인용 범위를 넘지 않는지 직접 확인하세요.
