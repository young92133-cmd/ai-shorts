## 주장 분류 요약 (확인된 사실 · 단순 계산 · 확인되지 않은 주장)

**확인된 사실** — 출처 종류를 함께 적는다(공식 = 기관 원문, 언론 = 기사 보도, 해설 = 금융사·언론 해설로 정부 원문과는 미대조)
| 주장 | 근거 |
|---|---|
| 본인이 신용점수를 조회해도 점수에 영향 없음 | 공식: 금융감독원 파인 |
| 상환이력(연체)이 신용평가의 가장 큰 요소, 일시적 소액연체는 평가에 쓰지 않음 | 공식: NICE평가정보 개인신용평점 안내 |
| 신용카드 15% · 체크카드·현금영수증 30%, 총급여 25% 초과분부터 공제 | 해설: KB Think·카드고릴라 등 (국세청 원문 미대조) |
| 연말정산 간소화 서비스 1월 15일 개통 | 언론: 2026년 1월 개통(=2025년 귀속) 보도 |
| 카페 김치볶음밥 약 3개월 40만 개, 컵떡볶이 2주 14만 개 이상, 편의점 5천 원 이하 식사형 상품 | 언론: 아시아경제 2026-10-19 (기업 발표 인용) |
| 정액관리비·관리비 항목 구분(일반관리비·사용료 등), 10만 원 이상 정액이면 세부 표시 | 언론: 국토교통부 2023년 제도 보도 |
| 1인당 구독 3~4개 39.8% 최다 | 언론: 대한상공회의소·엠브레인 2025년 2월 조사 보도 |

**단순 계산** (원고 안의 숫자로만 계산, 외부 사실 아님)
| 계산 | 비고 |
|---|---|
| 9,900+3,300+13,900+4,900 = 32,000원/월, ×12 = 384,000원 | 구독료 3장. 각 요금은 원고의 '예시' 금액(실제 특정 서비스 요금으로 확인한 것 아님) |
| 13,900원 × 12 = 166,800원 → "1년에 16만 원 넘게" | 구독료 5장. 같은 예시 요금 기준. 넷플릭스 스탠다드(13,500원, 비교 블로그 기준)로도 16만 2천 원 |

**확인되지 않은 주장** (수정본에서 쓰지 않았거나 문구에서 빼고, 추측해서 다른 숫자로 바꾸지 않음)
| 주장 | 처리 |
|---|---|
| 신용카드는 '한도 절반 아래'로 써야 한다 | 숫자 삭제 → "한도 꽉 채워 쓰지 않기" |
| 중복 OTT 하나만 끊어도 '연 15만 원'(자료: 15만~40만 원) | 삭제 → 위 계산값으로 대체 |
| 월 구독료 5만 원 이상 37% | 조사 원문 합계(46.6%)와 불일치, 카드 미사용 |
| 2026년 귀속(2027년 1월 정산)에도 공제율·25% 기준이 그대로인지 | 2차 자료상 현행 유지(개편안은 2027년 과세기간부터라는 설명)이나 정부 원문 미확인 → 아래 '연도 확인' |

## 연도 확인 (연말정산 편)

- 검수 근거 자료는 **2025년 귀속(2026년 1~2월 정산)** 기준이다. 지금(2026년 10월) 게시하면 독자가 맞을 정산은 **2026년 귀속(2027년 1월 정산)**.
- 카드·캡션에는 연도를 쓰지 않았고, 일정은 "보통 1월 15일"로 표현해 두 해가 섞이지 않는다.
- 2027년 1월 국세청 안내가 나오면 공제율·한도·간소화 개통일을 다시 확인한다(특히 세법 개정 시 공제율이 바뀌면 4장 비교 카드 수정).
