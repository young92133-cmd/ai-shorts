## 1. 채널 개요 (공개 지표)

- 시사·사회 이슈 쇼츠. 영상 소스 없이 **사진(이미지) + 나레이션 + 자막**만으로 만든다.
- 업로드량: 최근 60개가 2026-11-09 ~ 11-17, **9일에 60개(하루 6~7개)**.
- 조회수: 60개 **중앙값 20.8만**, 50만 이상 16개, 100만 이상 7개, 최저 1.2만.
- 길이: 29~43초. 롱폼(PUBG·원피스 해설 1.5~8분)도 있지만 주력은 쇼츠.
- 소재: 그 주의 한 이슈를 여러 각도로 연속 제작한다. 이번 주는 '수능·자격시험 AI 안경 부정행위'가 60개 중 약 20개,
  '젠슨황 사임·불륜' 9개. 같은 이슈를 "대책 / 반응 / 반전 / 다른 나라 / 관련 기관" 식으로 쪼갠다.
- 제목 공식: **[실시간/현재/역대급] + [대상] + [~라는/~한 이유/근황] + ㄷㄷ**
  예) "실시간 부정행위 준비 중이라는 N수생들 ㄷㄷ", "ai잡는 거 누구보다 자신있다는 공공기관", "선을 넘어버린 수능 쌀먹 근황 ㄷㄷ".
  전달형 어미(~라는, ~다는)로 '남이 한 말'을 옮기는 형태.

## 2. 화면 구성 (프레임 확인)

| 영역 | 세로 위치(대략) | 내용 |
|---|---|---|
| 위 검정 | 0 ~ 28% | 고정 제목 2줄: **윗줄 흰색, 아랫줄 노랑**, 굵은 각진 고딕, 외곽선 없음 |
| 가운데 사진 띠 | 28 ~ 74% | 장면 사진. 가로 꽉, 약 1.2:1. 사진 비율이 안 맞으면 같은 사진을 흐리게 깔고 가운데에 원본(블러 채움) |
| 사진 위쪽 안 | 띠 상단 | 반응 태그 `(!!!)` `(???)` `(ㄷㄷ)` `(수상...)` `(...)` 또는 따옴표 대사 `"좋은데??"` — **초록/노랑 글씨 + 검정 외곽선** |
| 사진 아래쪽 안 | 띠 하단 | 나레이션 자막 1줄(가끔 2줄), **딱 맞는 검정 박스**. 줄마다 글자색을 바꾼다 |
| 아래 검정 | 74 ~ 100% | 비워 둔다 (쇼츠 UI 버튼·설명 영역과 겹치지 않게) |

- 첫 0.5~1초: 회색 띠에 작은 제목만 있는 빈 화면(검정) — 바로 나레이션이 제목을 질문형으로 읽는다.
- 자막 색 규칙(관찰): 흰 글씨 = 평서·인용, **노랑 = 핵심 사실/숫자/장면 전환**, **빨강 = 부정·문제·충격**, **초록 = 대사·반전·커뮤니티 말**.
- 그래픽 덧칠: 빨간 화살표, 빨간 X, 큰 물음표, 빨간 원·밑줄(커뮤니티 글의 핵심 문장), 번쩍이는 효과.
- 장면 전환: 자막 한 줄(약 2~3초)마다 사진이 바뀌거나, 같은 사진에서 확대 영역만 바뀐다. 컷 6~14회/30~40초.
  같은 사진 연속일 때는 천천히 확대(Ken Burns).

### 사진 종류 (60개 공통)

1. **AI 생성 실사 장면** — 같은 인물(예: 뿔테 안경 수험생)을 여러 장면에 일관되게 등장시켜 '재연'한다. 가장 비중이 큼.
2. **커뮤니티 글·댓글 캡처** — 닉네임은 낙서/블러로 가림. 핵심 줄에 빨간 밑줄, 확대해서 한 줄씩 보여 준다.
3. **뉴스 헤드라인·기사 사진 캡처** — 상단에 헤드라인 문구만 잘라 붙이기.
4. **일러스트(이라스토야풍) / 밈 짤** — 기관·사람을 귀여운 캐릭터로. 감정 장면에 밈(개구리 등).
5. 달력·건물 외관·제품 사진 같은 설명용 스톡.

## 3. 대본 구조 (전사 3편 공통)

`제목 질문형 읽기(2~3초)` → `배경 "최근 ~ 논란인데"` → `발단 "한 ~가 ~라며 글을 올림"` → `전개(~했는데, ~하면서)`
→ `반전/결과 "~였던 거임", "~받았다고"` → `사람들 반응 "~라는 반응까지 나온다고"` → `한 줄 리액션 "와 이런 일이 점점 많아지네" / "아니 미쳤네"`

- 말투: 커뮤니티 썰체. **~거임, ~했다고, ~라며, ~인데** 로 끊고 맺음말을 생략한다. 존댓말 없음.
- 속도: 초당 약 6~7음절의 빠른 나레이션(목소리가 사람인지 AI 보이스인지는 판별하지 못했다).
- 한 문장 = 자막 한 줄 = 사진 한 장 단위로 리듬이 맞는다. 문장은 15~25자.
- 끝은 결론 정리 없이 화자 리액션 한 줄로 끊는다(반복 시청 유도).

## 5. 채택 / 복제 금지

채택(구조·원칙): 가운데 사진 띠 프레임, 흰+노랑 2줄 고정 제목, 줄별 색 박스 자막, 사진 위 반응 태그,
문장=자막=사진 리듬(2~3초), 썰체 7단 대본, 한 이슈를 여러 각도로 연속 제작하는 기획 방식, "~라는/~근황 ㄷㄷ" 제목 공식.

복제 금지: 채널명·정확한 색상값·폰트 파일, 원문 대본 문장, 채널이 만든 AI 이미지·일러스트,
커뮤니티 글·닉네임 원문 노출(캡처는 닉네임·프로필을 반드시 가리고 출처 표기), 실존 기관 로고를 캐릭터에 합성하는 방식.
실존 인물(예: 기업인)의 루머성 소재는 사실 확인된 보도만 쓴다 — Topic Strategy 의 verified 규칙 그대로.

## 6. 기존 profile 과 비교 → 판단

가장 가깝다: `curiosity_update_story`(질문 → 과거/배경 → 변화 → 현재·반응 → 답, narrated, 사진·영상).
다른 점은 ① 장면이 문장 단위로 잘게(8~14장) ② 근거 자료가 커뮤니티 글·기사 캡처 ③ 마지막이 질문이 아니라 화자 리액션 한 줄
④ 썰체 말투 — 모두 **대본 지침·장면 분할·편집 스킨** 차이라 구조(beats) 자체는 같다.
→ **새 profile 을 만들지 않고 `curiosity_update_story` 의 variation + 편집 스킨**으로 반영하는 것을 권장한다(러블릿→fantube 와 같은 방식).

## 7. 구현 제안 (기록)

`curiosity_update_story` variation(`issue_photo`) + 편집 스킨 `issue`(fantube 코드 재사용):
1. `frame_layout="band"` — 위 28% 검정 제목, 가운데 46% 사진 띠(cover, 비율 안 맞으면 블러 채움), 아래 26% 검정.
2. ASS: 같은 크기 2줄 제목(흰/노랑), `ISLine` 박스 자막(띠 하단), 줄 앞 `[노랑]` `[빨강]` `[초록]` 색 지정, 장면 `tag` → 띠 상단 반응 태그.
3. 대본 profile: 질문형 제목 읽기 → 배경 → 발단 → 전개 → 반전 → 반응 → 한 줄 리액션, 썰체, 문장 15~25자, 문장마다 장면 1개.
4. 커뮤니티/기사 카드 생성기: 글 텍스트를 '게시글 모양' 이미지로 그리고 닉네임은 가림 처리, 핵심 줄 빨간 밑줄.
5. 도형 오버레이 세트(화살표·X·원·물음표)와 장면별 `marks` 필드.
6. 효과음은 fantube 것 재사용(사진 바뀔 때 whoosh).
