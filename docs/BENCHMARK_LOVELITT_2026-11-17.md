## 1. 채널 개요 (공개 지표)

- 아일릿(ILLIT) 단일 그룹 팬튜브. 소재 = 예능·위버스 라이브·자체 콘텐츠의 멤버 리액션 한 장면.
- 최근 쇼츠 40개: **중앙값 3.8만**, 10만 이상 11개. 상위: `모카 너무 귀여움` 730만, `술 마시고 연애 공개하는 원희` 330만,
  광고 패러디 88.7만, 신곡 52.8만. 롱폼은 ASMR 편집(16만대), 가사/해석(84만)이 강하다.
- 제목 공식: **[멤버 이름] + [상황/행동 한 줄] + ㅋㅋ/ㅠ** (예: "다구리맞는 윤아 ㅋㅋ", "원희한테 선 긋는 유병재").
  설명이 아니라 '이 장면에서 일어나는 일'을 그대로 말한다.
- 채널 운영 측 주장(보조 영상): 첫 3초 훅, 지루한 구간 0.1초 단위로 잘라 길이 줄이기, 18시 전후 업로드,

## 3. 구조 (일반화)

`상단 고정 제목(상황 한 줄 + ㅋㅋ)` → `원본 장면 재생 + 대사 박스 자막` → `리액션 지점마다 효과 자막·사진·효과음` → `웃음 포인트에서 끝`

- 나레이션 없음. 원본 대화가 이야기를 끌고, 편집자는 자막·효과·사진으로 **해석과 타이밍**을 더한다.
- 길이: 상위 쇼츠는 수십 초 단위 한 장면. 군더더기 구간은 잘라낸다.
- 돌토리(`kpop_observation_clip`)와 차이: 돌토리는 "볼 이유 → 근거 → 해설 → 질문"의 관찰형,
  러블릿은 **예능 장면 리액션 강조형**(웃긴/귀여운 순간 하나를 자막·효과로 증폭).

## 5. 채택 / 복제 금지

채택(구조·원칙): 열린 하단 프레임, 작은 2줄 제목, 각진 폰트 + 좁은 자간, 대사 박스 자막, 감정별 효과 자막,
ease-out·슬라이드 등장, 강조 블러, 변화 시점 효과음, "멤버 + 상황 + ㅋㅋ" 제목 공식.

복제 금지: 러블릿 채널명·로고·정확한 색상값·자막 템플릿 파일, 원본 영상·대사 문장, 이라스토야 이미지의 무단 사용.
원본 예능/위버스 영상은 권리 확인이 안 된 소스다 — 기존 정책대로 `--quote`(transformative_quote) 또는 권리 확인 영상만 쓴다.

## 6. 구현 (2026-11-18) — 새 profile 없이 편집 스킨 `fantube`

구조는 kpop_observation_clip 과 같아서 profile 을 새로 만들지 않고 렌더 스킨으로 넣었다 (`app/pipeline/fantube.py`).
- 사용: `make … --skin fantube`, `rerender <id> --skin fantube [--headline …] [--headline-accent …] [--no-sfx]`, `benchmark plan … --skin fantube`
- timeline.json 의 `skin`·`headline`·`sfx` 로 저장 → rerender·CapCut 내보내기에서 유지
- 자막 표시: 문장 앞 `[화남]`(빨간 흔들림)·`[억울]`(파란 내려앉기)·`[강조]`(뒤 영상 블러)·`[스토리]`(왼→오 밀며 등장), 단어 `*강조*`
- 효과음: 장면 전환 whoosh, 자막 pop, 화남 hit, 억울 drop — ffmpeg 합성, 외부 음원 없음
- 한계: 원본 영상은 아래까지 채우려고 좌우를 잘라낸다(관찰 근거가 화면 가장자리에 있으면 default 스킨). 카드·이미지는 잘리지 않게 양옆 검정. 실제 쇼츠 제작 검증 전.

### 당시 제안 (기록)

새 profile `fan_reaction_clip` + 렌더 스킨 `fantube`:
1. `frame_layout="open_bottom"` — 위 14~16% 검정 제목바, 영상은 가로 꽉 채워 하단까지(위쪽 기준 crop).
2. ASS 스타일 `TitleAccent`/`TitleMain`(2줄), `Line`(타이트 박스·얇은 고딕·Spacing -2), `Emphasis`(강조색), 감정 프리셋 3종(평범/억울/화남).
3. 등장 애니메이션: `\move`+`\t(\fscx\fscy)` ease-out, 스토리 자막은 왼→오 슬라이드.
4. 효과음 트랙: 컷 전환·자막 시작 시점에 무료(CC0) 효과음 배치, 원본 대비 -12dB.
5. 나레이션 없는 원본 음성 모드.
