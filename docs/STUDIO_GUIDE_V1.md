# 카드뉴스·인스타툰 스튜디오 V1.0 사용 안내

개인용 PC 프로그램 V1.0 기능 기준선 (2026-10-21). 이 문서에 적힌 기능이 V1.0 범위이고, 이후에는 새 기능보다 콘텐츠 품질과 안정성을 먼저 개선한다.
버전은 이 문서로만 표기한다(Git 태그·Release 는 만들지 않음).

## 실행

1. 프로젝트 폴더의 `카드뉴스 스튜디오 실행.cmd` 를 더블클릭 → 브라우저에 http://127.0.0.1:8765/studio 가 열린다.
   (쇼츠 화면 `AI Shorts 실행.cmd` 왼쪽 메뉴에도 링크가 있다. 같은 프로그램, 같은 서버)
2. 처음 한 번: Claude 구독 로그인이 필요하다. 풀렸으면 `claude-login.cmd` 를 실행한다. 확인: `claude auth status`.
3. 이 PC 에서만 열린다(127.0.0.1). 주소 끝에 `#<프로젝트 id>/<장>` 을 붙이면 그 카드를 바로 연다.

## 만들기

왼쪽 **+ 새로 만들기** → 주제 · 형식(카드뉴스 / 인스타툰 / 섞기) · 장수(6~10) · 템플릿 · 캐릭터 · 공개 사진 찾기 · 추가 요청 → **만들기**.
보통 1~3분. 문구는 Claude 구독으로 쓰고(편당 2~4회 호출), 그림은 등록된 햄토리치 포즈·앱이 그린 배경·권리가 확인된 공개 사진만 쓴다.
유료 API·이미지 생성 API 는 쓰지 않는다.

## 고치기 (카드를 고르면 미리보기 옆에 버튼)

| 하고 싶은 것 | 방법 |
|---|---|
| 문구·대사 고치기 | 오른쪽 칸 수정 → **저장하고 다시 그리기** (그 카드만 다시 그림) |
| 카드 종류 바꾸기 | '카드 종류'(표지·훅·정보·체크리스트·비교·인용·요약·마무리) → 저장. 필요한 칸은 지금 문구로 채운다. 비교 카드는 양쪽 제목·항목 칸 |
| 만화 장면 바꾸기 | 컷별 감정·자세·배경·카메라 선택, 또는 **장면 바꾸기**(다음 후보로 자동) |
| 순서 · 추가 · 삭제 | **◀ 앞 / 뒤 ▶**, **+ 카드 추가**, **+ 만화 컷**(카드뉴스 제외), **카드 삭제** (3~10장) |
| 내 이미지 넣기·교체·빼기 | **🖼 이미지 넣기·교체** → 권리 확인 → PNG·JPG·WEBP(20MB, 약 4천만 화소 이하). **이미지 빼기**. 순서를 바꿔도 그 카드를 따라간다 |
| 되돌리기 | 위쪽 **↶ 실행 취소(n)** / **↷ 다시 실행(n)**. 새로 편집하면 다시 실행 목록은 비워진다 |

바꾸기 전 상태는 프로젝트의 `<형식>/history/` 에 남고, 쓴 기록은 `history/undone/` 으로 옮겨질 뿐 지워지지 않는다.

## 저장

- **PNG 전부 저장 (ZIP)**: 카드 PNG(1080×1350) + `caption.txt`(캡션·출처) + `sources.json`(출처 대장).
- **캡션 복사**: 인스타그램 본문용.
- 결과 폴더: `output/<프로젝트 id>/<형식>/` (`card_NN.png`, `plan.json` 문구, `manifest.json` 기록).

## 게시 전 확인 (V1.0 운영 원칙)

1. AI 가 쓴 **숫자·통계는 출처와 대조**한다(판매량·공제율·금리 등). 틀리면 문구를 고친다.
2. 출처 이름이 '자료 1' 처럼 불분명하면 캡션 출처를 직접 다듬는다.
3. 직접 올린 이미지는 쓸 권리가 있는 것만(직접 찍음·만듦·사용 허락).
4. 만화 컷 표정이 대사와 안 맞으면 '감정'을 바꾸거나 장면 바꾸기. 화면 위 "맞는 표정 그림이 없어…" 안내는
   새 포즈 그림이 필요하다는 뜻이다(목록·만드는 법 `characters/hamtorich_01/README.md`).

## 알려진 한계 (V1.0)

- 햄토리치 승인 포즈 8종이라 놀람·슬픔·무표정이 비슷한 그림으로 대신 그려진다.
- 무료 공개 사진은 맞는 것이 자주 없어 카드뉴스가 그래픽 위주가 된다 → 직접 이미지로 보강.
- 실행 취소·순서 편집은 전체를 다시 그려 몇 초 걸린다. 공개 사진 다시 찾기는 없다.
- 카드↔만화 컷 종류 바꾸기는 없다(삭제 후 추가).

## 개발자용

전체 테스트 `.venv\Scripts\python.exe -m unittest discover -s tests -q` (V1.0 기준 405개).
