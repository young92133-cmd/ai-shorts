# Topic Strategy Engine V1 구현 계획 (2026-10-08)

기존 상태: 미커밋 변경 없음. `research.py`는 Naver/DDG/RSS와 기사 추출, `batch.py`는 저장된 trends 후보,
`bench_auto.py`는 쇼츠 구조 평가, `carousel`은 Master/Planner/Renderer와 Character Registry를 제공한다.
주제 전략/사실 검증/발행 이력/캘린더는 아직 없다. 기존 `make` 명령과 쇼츠 파이프라인을 유지한다.

1. 후보/근거 스키마와 원자적 JSON 저장. 기존 뉴스 검색·기사 추출·SourceRegistry 재사용. RSS/공식 자료/통계/직접 입력/trends JSON.
2. 주장 단위 검증(근거 원문·공식 도메인·수치 기준일/단위·적용대상·원통계·충돌/기한), 4항목 100점 평가, 사건 병합과 30/90일 이력.
3. 검증된 사실만 Master/8페이지 스토리로 변환. 자체 Character Registry, 기존 캐러셀에 저장된 Master/plan 주입.
4. 고객 교육 업종·활용·납품물/리스크 추천. 객관적 교육과 광고 분리.
5. 최근 20슬롯 9:7:4, 1/4주 캘린더, 승인·수정·보류·검토·발행 기록과 CLI/자연어 연결.

각 단계 mock 테스트, 최종 전체 회귀. 실제 Claude/유료 API 및 실 PNG 생성은 이번 작업에서 실행하지 않는다.
최종 결과는 테스트용 가상 근거라고 표시된 오프라인 데모(10후보·상위3·캘린더·story JSON)로 남긴다.
게시 API는 추가하지 않으며 published는 사용자 확인에 따른 이력 기록이다. 자동 검증은 원문 일치 기반의 보수적 게이트이고
복잡한 법률/금융 해석은 검토 보류한다. RSS 엔드포인트를 추측하지 않고 사용자가 등록한 공개 출처를 받는다.
