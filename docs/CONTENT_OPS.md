# 콘텐츠 운영 안내 (V1.0 운영 단계, 2026-10-21~)

새 기능 개발은 멈추고 실제 게시·품질 개선에 집중한다. 게시 묶음은 `output/_publish_<날짜>/`(Git 밖), 검수 근거는 `docs/QA_REVIEW_*.md`.

## 1. 한 편이 게시되기까지

1. 스튜디오에서 만들기 → 2. 카드별 확인·수정(실행 취소 가능) → 3. 숫자·출처 검수(확인된 사실 / 단순 계산 / 미확인 구분, 미확인은 문구에서 빼기)
→ 4. 게시 묶음 폴더의 `checklist.md` 모두 체크 → 5. 게시 → 6. `ops_data/content_log.csv` 에 한 줄(1주일 뒤 반응 숫자).
세법·정책처럼 해마다 바뀌는 내용은 그해 공식 안내 확인 전까지 **게시 보류**.

## 2. 운영 기록 — 양식은 Git, 실제 데이터는 내 PC 에만

| 파일 | 내용 | GitHub |
|---|---|---|
| `docs/content_log_template.csv` | 공통 양식(머리줄만). 열을 바꿀 때만 고친다 | 올림 |
| `ops_data/content_log.csv` | **실제 운영 기록**(게시일·조회수·저장수 등 개인 운영 데이터) | 올리지 않음(`.gitignore`) |

`ops_data/` 는 Git 밖이므로 게시 묶음 백업 ZIP 에 함께 넣어 보관한다. 엑셀에서 바로 열린다(UTF-8 BOM). 한 편에 한 줄.

| 열 | 적는 것 | 어디서 |
|---|---|---|
| 제작_초 · AI_호출 | 제작 시간, Claude 구독 호출 수 | 진행 표시 / project_state.json `ai_calls` |
| 수동_수정_수 · 수정_종류 | 사람이 고친 칸 수와 종류(제목·본문·대사·비교·출처·캡션·이미지·순서) | 스튜디오 실행 취소 숫자, 검수 보고서 |
| 사실_문제_수 | 검수에서 나온 과장·불일치·미확인 수 | 검수 보고서 ⚠·❓ |
| 표정_대체_컷 · 대체_레이아웃 | 맞는 표정 그림이 없어 대체된 컷, 깨져서 안전 레이아웃으로 그린 장 | 스튜디오 화면 위 안내 / manifest `pose_gaps`·`fallback_pages` |
| 게시_상태 · 게시일 | 게시 가능 / 게시 보류 / 게시함 / 취소, 날짜 | |
| 조회수 · 저장수 · 공유수 · 댓글수 | 게시 1주일 뒤 인스타그램 인사이트 숫자(직접 옮겨 적음, 자동 수집 없음) | 인스타그램 앱 |
| 메모 | 눈에 띄는 반응·다음에 고칠 점 | |

한 달에 한 번 보는 것: 편당 평균 수동 수정 수(줄어드는지), 사실 문제가 반복되는 유형, 표정 대체가 많은 감정, 저장수가 높은 형식 → 다음 개선 우선순위.

## 3. 햄토리치 표정 자산 제작 계획 (원본 그림은 바꾸지 않음)

**현재 부족한 것** (지금까지 만든 만화·혼합형 전체, 햄토리치 컷 65개 기준)

| 감정 | 쓰인 컷 | 대체된 컷 | 지금 대신 쓰는 그림 | 우선 |
|---|---|---|---|---|
| 놀람 | 9 | 7 | worried_hands(걱정) | 1 |
| 고민(웃지 않는 생각) | 생각 14 | 0으로 집계되지만 14컷 모두 **웃는** thinking_chin | thinking_chin(미소) | 2 |
| 슬픔 | 3 | 2 | worried_hands | 3 |
| 무표정 | 1 | 1 | happy_front(웃음) | 4 |

자세한 파일 이름·표정 설명은 `characters/hamtorich_01/README.md` '아직 없는 그림' 표.

**만드는 방법 (유료 API 없이, 그림체 유지 순서로 추천)**

1. **얼굴만 바꾼 변형(가장 안전)** — 이미 승인된 포즈 PNG 를 무료 편집기(Krita·Photopea 등)에서 열어 **눈·눈썹·입만** 다시 그린다.
   몸·옷·외곽선·색은 원본 그대로라 그림체가 어긋나지 않는다. 놀람(happy_front 몸 + 동그란 눈·O 입), 고민(thinking_chin 몸 + 다문 입·한쪽 눈썹),
   무표정(happy_front 몸 + 작은 일자 입)에 맞다. 원본 파일은 덮어쓰지 않고 새 이름으로 저장.
2. **새 자세가 필요한 것** — 슬픔(어깨 처짐·앉음)은 몸이 달라 1번이 어렵다. 직접 그리거나, 이미 쓰고 있는 이미지 도구(구독 중인 것만)에
   `master/design_sheet.png` + 기존 포즈 2~3장을 함께 넣고 `bible.json` 의 `prompt_lock`·`design_rules` 를 붙여 만든다.
3. **검수 기준(승인 전 필수)** — 마스터 시트와 나란히 놓고: 얼굴형·귀 위치/색, 갈색 외곽선 굵기, 네이비 정장·민트 넥타이, 털 색, 머리·몸 비율,
   투명 배경 1254×1254(또는 흰 배경), 그림 안 글자·말풍선·효과선 없음. 하나라도 다르면 승인하지 않는다.
4. **등록** — `assets/inbox/햄토리치_<감정>_<자세>.png` 로 넣기 → `python -m app.factory characters import` → `characters show hamtorich_01`
   → 대조 후 `characters approve --item hamtorich_01/poses/<파일>.png`. 미승인 그림은 렌더에 쓰이지 않는다.
5. **확인** — 표정 대체가 있던 수정본(점심값·관리비·구독료)의 해당 장을 스튜디오에서 '저장하고 다시 그리기' → 화면 위 표정 대체 안내가 사라지는지 본다.
   AI 호출 없이 그림만 바뀐다.

1차 목표: 놀람·고민·무표정 3장(얼굴 변형) → 2차: 슬픔 1~2장(새 자세). 4장만 추가해도 지금까지의 대체 11컷이 모두 맞는 표정이 된다.
제작 사양(기준 그림·색·크기·검수표)은 `characters/hamtorich_01/EXPRESSION_SPEC.md`.
