# 그림 받은편지함

ChatGPT 등에서 만든 그림을 이 폴더에 넣으면 다음 제작 때(또는 `python -m app.factory characters import`) 자동 등록된다.

- 배경: `bg_<장소>_<시간>.png` — 예) `bg_원룸_밤.png`, `bg_마트_계산대.png`, `bg_은행_창구.png`, `bg_퇴근길_골목_노을.png`
  → 1080×1350 으로 맞춰 `assets/carousel_backgrounds/` 에 등록. 컷의 장소 문구와 단어가 맞으면 그 컷 배경으로 쓴다.
- 캐릭터: `<캐릭터>_<감정>_<자세>.png` — 예) `햄토리치_놀람_서있음.png`, `햄토리치_걱정_영수증.png`, `다람_행복_쇼핑.png`
  → 투명 PNG 권장. 흰 배경이면 자동으로 지운다. 처음 보는 이름은 새 조연 캐릭터로 만든다.
  감정: 기본·행복·놀람·걱정·생각·자신감·슬픔·화남 / 자세: 서있음·가리킴·설명·손흔듦·팔짱·턱·만세·어깨·달리기·앉음 (그 밖의 단어도 그대로 자세 이름이 된다)
- 처리한 원본은 `_done/<날짜>/` 로 옮겨진다. 분류하지 못한 파일은 그대로 두고 이유를 알려 준다.
  같은 이름의 원본이 이미 있으면 `_2`, `_3` 등을 붙여 기존 원본을 보존한다.

ChatGPT 에 그릴 때: 햄토리치 디자인 시트(`characters/hamtorich_01/master/design_sheet.png`)와 기존 포즈 PNG 를 함께 올리고
"같은 캐릭터, 같은 그림체, 투명(또는 흰) 배경, 글자·말풍선 없음" 을 요청한다. 배경은 "인물·글자 없음, 세로 4:5" 로 요청한다.
